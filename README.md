# 스케줄 알람 ⏰

교대근무자를 위한 Android 근무 일정·모닝콜 앱입니다. 순환 근무 패턴으로 일정을 만들고 주간·야간 출근 시간에 맞춰 알람을 받을 수 있습니다.

## 다운로드

- [최신 정식 버전](https://github.com/kangheechoul/schedule_alam-releases/releases/latest)
- [모든 버전과 개발 버전](https://github.com/kangheechoul/schedule_alam-releases/releases)
- [버전별 패치 내역](./CHANGELOG.md)

`stable`은 일반 사용자를 위한 정식 버전이고, `pre-release`는 실제 기기 검증을 위한 개발 버전입니다.

## 주요 기능

- 주간·야간·운휴·비번·휴무 순환 패턴 기반 일정 생성
- 달력·목록 조회와 날짜별 직접 수정
- 고정 시각 및 출근 시간 기준 유동 알람
- 주간·야간별 알람 시각과 Android 내장 알람음 설정
- 잠금화면 전체화면 알람, 반복 모닝콜과 재울림
- 근무표 사진을 읽어 일정을 입력하는 온디바이스 OCR
- 공휴일·휴가와 다크·라이트 테마 표시

## 설치 방법

1. Releases의 Assets에서 `app-release.apk`를 내려받습니다.
2. Android에서 출처를 알 수 없는 앱 설치를 허용합니다.
3. APK를 실행해 설치합니다.

기존 버전 위에 설치하면 앱 데이터는 유지되지만, 중요한 일정은 업데이트 전에 확인하는 것을 권장합니다.

## 처음 사용할 때

1. 앱을 실행하고 알림 권한을 허용합니다.
2. 필요하면 Android의 `알람 및 리마인더`에서 정확한 알람을 허용합니다.
3. 설정에서 순환 근무 패턴과 시작 날짜를 입력합니다.
4. 알람 방식, 주간·야간 시각, 재울림과 알람음을 설정합니다.
5. 달력에서 생성된 일정과 알람 시각을 확인합니다.

## 알람 방식

- **고정 시간:** 일정에 저장된 시각에 알람이 울립니다.
- **유동 시간:** 출근 시각에서 주간·야간별 사전 시간을 빼서 알람이 울립니다. 출근이 09:00이고 2시간 전으로 설정했다면 07:00에 울립니다.

알람 화면에서 `오늘 알람 전체 끄기`는 오늘 남은 재울림까지 취소하며, `이번만 끄기`는 다음 재울림을 유지합니다. Android에서는 미디어 음량이 아닌 시스템 알람 음량을 사용합니다.

## 근무표 사진 스캔

- 설정에서 카메라 또는 앨범의 근무표 사진을 선택할 수 있습니다.
- OCR은 기기 안에서 처리하며 근무표 이미지를 서버로 전송하지 않습니다.
- 표 모양·해상도·글꼴·촬영 각도에 따라 결과가 달라질 수 있으므로 저장 전에 반드시 확인하세요.

## 일정과 데이터

- 일정, 패턴과 설정은 기기의 앱 저장 공간에 보관됩니다.
- 직접 수정한 일정은 패턴 재적용 시 보존하도록 선택할 수 있습니다.
- 휴가로 지정한 날짜에는 알람이 예약되지 않습니다.
- 앱을 삭제하면 기기에 저장된 일정과 설정도 삭제될 수 있습니다.

공휴일 데이터는 공공데이터포털의 한국천문연구원 [특일 정보](https://www.data.go.kr/data/15012690/openapi.do)를 사용합니다.

## 지원 환경과 주의사항

- Android가 주 지원 대상입니다.
- OCR, 내장 알람음과 전체화면 알람은 설치 APK에서 동작합니다.
- 정확한 알람과 전체화면 표시는 Android 버전 및 제조사 절전 정책에 따라 달라질 수 있습니다.
- APK 설치 전 릴리스 자산에 표시된 SHA-256을 확인할 수 있습니다.
